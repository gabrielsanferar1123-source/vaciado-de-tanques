Método del artículo de Plaza Gálvez (2017)

Regresión, diferenciación numérica y ecuaciones diferenciales a partir de mediciones h(t). Unidades del artículo: cm y min.

A

Datos para el análisis

Elige qué mediciones se analizan.

Con σ = 0 se analiza la solución teórica exacta muestreada cada Δt. Un σ > 0 imita errores de lectura con regla y cronómetro.

Acepta tabulador, espacio o punto y coma, y coma o punto decimal (se puede pegar desde Excel).
